# Contributing

## Development

Use Python 3.12 on Windows, create a virtual environment, then install `requirements.txt`.
Run `python -m pytest tests -q` before opening a pull request.

## Pull requests

- Keep each pull request focused.
- Do not commit API keys, local configuration, screenshots, build folders, or model caches.
- Include a short reproduction note for bug fixes and screenshots for visual changes.

## Good first contributions

- OCR accuracy and multilingual testing
- overlay typography and accessibility
- translation-provider adapters
- Windows DPI and multi-monitor compatibility
